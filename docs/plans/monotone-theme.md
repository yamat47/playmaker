# モノトーン化と Material 配色

> **この文書の役割**: 芝を白にして図をモノトーンにし、配色全体を Google の Material Design の
> パレットに寄せる変更の計画。2026-11-03 にユーザーと決めた判断と、PR の分け方を書く。
> 位置の格子化（PR #122）の続き。

## 判断（2026-11-03 に決着）

| # | 論点 | 結論 |
|---|---|---|
| M1 | フィールド | **全部グレー**。芝は白、ライン・数字・ハッシュは濃淡のグレー、エンドゾーンとサイドラインの外は薄いグレー、パイロンとゴールポストもグレー。5 ヤードごとの芝の帯は無くす |
| M2 | 配色の出どころ | **Material Design のパレット**。フィールド、選手、線、選択、ツールバーとパネル、demo のページまで同じパレットで揃える |
| M3 | 選手の既定 | **黒の枠線のみ**（塗らない）。プリセットは攻守とも既定のままで、ディフェンスの赤は無くす |
| M4 | 塗りつぶしと枠線 | 形とは独立した選手の値（`fill: "outline" \| "solid"`）として持つ。パネルでは「塗りつぶしか枠線か」を別の選択肢にせず、色の選択肢の中に塗りつぶしの色と枠線のみの色を並べる |
| M5 | 選手の色 | **4 色のパレット**（黒、赤、青、緑）を塗りつぶしと枠線の 2 通りで、8 つのスウォッチにする。自由な色の入力は無くす |
| M6 | 線の色 | 同じ 4 色（黒、赤、青、緑）。既定は黒 |
| M7 | 格子 | edit モードだけに薄いグレーで敷く（PR #122 の仕組みのまま色だけ変える） |

## 配色

Material Design の色を使う。canvas の既定値は `browser/theme/tokens.ts`、UI は `styles.css`、demo は `demo/index.html` に書く。

| 用途 | 値 |
|---|---|
| 芝 | `#ffffff` |
| エンドゾーン | `#f5f5f5`（grey 100） |
| サイドラインの外 | `#eeeeee`（grey 200） |
| ライン、ハッシュ、矢印 | `#9e9e9e`（grey 500） |
| 数字 | `#bdbdbd`（grey 400） |
| ゴールライン | `#616161`（grey 700） |
| パイロン、ゴールポスト | `#9e9e9e`（grey 500） |
| 格子 | `rgba(0, 0, 0, 0.1)` |
| 黒 / 赤 / 青 / 緑 | `#212121`（grey 900）/ `#d32f2f`（red 700）/ `#1976d2`（blue 700）/ `#388e3c`（green 700） |
| 選択 | `#ff9800`（orange 500）。パレットに無い色なので線と紛れない |
| UI のアクセント | `#1976d2`（blue 700） |
